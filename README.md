# Buzón de sugerencias · base vacía para el recorrido en vivo

Solo trae una página vacía, la configuración del Codespace y las reglas de trabajo (`CLAUDE.md`).
Se construye todo con los 7 pedidos de `docs/RECORRIDO_INSTRUCTOR.md`.

El código terminado está en el repositorio `plantilla-buzon-s7` (plan B si el tiempo o la red fallan).

Variables que necesitará más adelante: `ANTHROPIC_API_KEY`, `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `CLAVE_REVISOR`
(secretos del Codespace o `export`; en Vercel, Environment Variables). Nunca en archivos.
